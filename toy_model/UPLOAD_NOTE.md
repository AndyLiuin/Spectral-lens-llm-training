# Toy-Model Scripts

This is the local `toy_model/` code needed for the modular-arithmetic and
Fourier toy-model experiments.

Useful entry points:

- `run_concat_batch_regime_ablation.py`: cumulative Baseline/RoPE/Muon/Untied
  batch and learning-rate sweeps.
- `run_feature_learning_probe.py`: Fourier/feature probes on saved checkpoints.
- `run_feature_learning_upgrade_pipeline.py`: combined training/probe pipeline.
- `plot_toy_main_2x2.py` and `plot_toy_figure4_candidates.py`: figure
  generation utilities.

Large run folders are intentionally excluded from the upload bundle.
